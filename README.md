# 韩地核对（KoreaPlaceCheck）

一个免费、免安装的手机网页小工具，用来解决去韩国旅行时最烦的问题：

> 在 Naver Map 搜出来的结果，到底是不是攻略里说的那一家？

它不做导航，也不做地图——导航仍然交给 Naver Map。它只负责三件事：**看懂攻略 → 打开正确的搜索 → 带回资料核对**。

## 适用场景

- 攻略（小红书 / 博客 / 朋友消息）里只有中文名，不知道韩文原名。
- Naver Map 搜出一堆同名店，分不清是本店还是分店（본점 / 홍대점 / 성수점…）。
- 想把确认过的地点存成清单，附中文备注和官方链接。

## 位置

- 网页文件：`f:\AI\App\KoreaPlaceCheck\index.html`
- 本说明：`f:\AI\App\KoreaPlaceCheck\README.md`

## 功能一览

| 功能 | 说明 |
|---|---|
| 攻略解析 | 自动从贴入的文字中挑出店名（韩文优先，其次英文）、地址、电话、区域（弘大/圣水/江南…，自动对应韩文名和所属区） |
| 生成搜索链接 | 生成最多 4 个 Naver Map 官方搜索链接（店名 / 店名+区域 / 地址 / 电话） |
| 截图粘贴 | 电脑：点虚线框后按 `Ctrl+V` 或拖入；手机：点「选择图片」从相册选 |
| 带回核对 | 把 Naver Map 上的店名 / 电话 / 地址 / 分享链接贴回来，逐项比对 |
| 比对报告 | 显示哪些资料一致、哪些冲突，给出「可保存 / 有冲突 / 证据不够」的结论 |
| 保存清单 | 确认过的地点存在浏览器 localStorage，附 Naver Map 链接，可随时重新打开 |

## 操作流程

### 第 1 步：贴攻略
打开网页，把攻略内容贴进左侧大输入框——文字、网址、店名、地址、电话都可以混着贴。
下方会立即出现识别结果（店名 / 区域 / 地址 / 电话）。
有完整韩文地址的那一行会被当成地址，不会被误当成店名。

### 第 2 步：生成搜索并打开 Naver Map
点「生成 Naver Map 搜索」，右侧会出现最多 4 个搜索入口：
- **推荐搜索：店名**：韩文店名优先，没有就用英文店名。
- **店名 + 区域**：例如 `MILESTONE COFFEE 성수`，用来分清同名分店。
- **用地址搜 / 用电话搜**：攻略里有地址或电话时出现（电话最准，`+82` 国际格式会自动转成韩国本地格式）。
- 点「打开 Naver Map」→ 进入真正的地图；在手机上通常会直接跳进 Naver Map App。

### 第 3 步：在地图里确认
搜索结果下方会出现「怎么选」提示（例如攻略说圣水 → 选店名有 성수、地址在 성동구 的那家）。
看不懂韩文时，展开「看不懂韩文？Naver Map 操作说明」：有手机 App / 电脑网页的操作步骤和常见韩文对照（복사＝复制、공유＝分享、주소＝地址…）。

点进最像的那家地点详情页，复制回来（地址或电话有一样就能比对）：
1. **分享链接**（地点页的分享按钮）
2. **店名**（建议保留韩文）
3. **地址 + 电话**（这两样是比对的最强证据）

### 第 4 步：贴回工具比对
在 Naver Map 复制地址（或电话、分享链接），回到工具按「📋 贴上 Naver 复制的内容」。
工具会自动分辨贴进来的是店名 / 电话 / 地址 / 链接，填进对应栏位并**自动比对**，不用自己一格一格填。
- 可以连续贴好几样（例如先贴地址、再贴链接），会累加，不会互相覆盖。
- 按钮读不到剪贴板时（第一次可能要允许权限），长按下面的小框选「粘贴」也一样。
- 想看或修改识别结果，展开「查看 / 手动修改」。

第 1 步也一样：复制攻略后按「📋 贴上攻略并搜索」，会直接生成搜索并清掉上一家的地图资料，开始核对下一个地点。

工具会输出结论：
- ✅ **一致，可保存**：电话或门牌地址对得上（或名称和区域都对得上），且没有任何冲突。
- ⚠️ **有冲突**：例如电话、区、门牌号、分店对不上，可能搜到了同名店或错分店。
- ➖ **证据不够**：只有部分对上，需要再补地址或电话。

每一项会标示 ✓ 一致 / ✗ 冲突 / ？ 无法自动判断。比对规则：
- **地址**：只比「城市 + 区 + 路名 + 门牌号」，所以 `서울` 和 `서울특별시`、后面多写 `1층`（楼层）都不影响。
  道路名地址和旧地番地址（如 `성수동2가 315-63`）无法互相换算，会标 ？ 并提示你去看另一种写法。
- **区域**：攻略写中文地名（圣水、弘大、明洞…）时，会对照该地名所在的区（성동구、마포구、중구…）。
- **名称**：攻略是英文/中文、地图是韩文时无法自动比对，会标 ？ 请你看招牌，不会误判成冲突。
- **分店**：攻略写「本店」或 `본점`，地图却是 `강남점` 之类，会判为冲突。

### 第 5 步：保存到清单
点「保存已确认地点」，地点会带比对结论（一致 / 有冲突 / 证据不够）和官方链接进入清单，之后随时点「打开」回到 Naver Map。
有冲突时按钮会变成红色「仍要保存（有冲突）」，提醒你再确认一次。
分享链接只接受 `http(s)://` 网址，填错时会改用 Naver Map 搜索链接。

## 截图怎么用

- 电脑：点两个虚线框后直接按 `Ctrl+V`，不用先存图；也可以把图片拖进去。
- 手机：点虚线框里的「选择图片」从相册选（手机无法在虚线框里长按粘贴）。
- **攻略截图**放在左边：门头照、菜单、招牌。
- **地图截图**放在右边：Naver Map 地点页（含地址、电话、照片）。
- 目前截图用于**并排人工核对**：招牌文字、Logo、门头是否一致。
  真正的自动图像识别（OCR / 视觉比对）需要额外服务，暂未包含。

## 判断优先级（为什么这样比对）

可信度从高到低：

1. **电话**完全一致 → 基本可以确认是同一家
2. **完整地址**（城市 / 区 / 洞 / 街道）
3. **分店与区域**（본점 / 홍대점…；攻略说圣水就不能是弘大）
4. **正式韩文店名**
5. 地图位置、招牌文字、照片

注意：中文译名相似 ≠ 同一家。韩国同名店很多，只凭名称不要直接导航。

## 启动方式

### 电脑本地使用
直接双击 `index.html` 用浏览器打开即可。

### 手机访问（同一 Wi-Fi）
在项目目录运行：

```powershell
npx serve -l 4173 .
```

手机浏览器打开 `http://<电脑局域网IP>:4173`（启动时会显示实际地址）。
首次打不开通常是 Windows 防火墙拦住了端口，需允许 Node.js / 4173 端口的局域网访问。

### 供朋友在外网使用
这是纯静态网页，部署到 GitHub Pages / Cloudflare Pages / Vercel 即可，无需服务器费用。

## 隐私与限制

- 填过的文字会自动暂存在浏览器里：手机在 Naver Map App 和浏览器之间切换、页面被重新载入时，内容会自动恢复（截图不会保留）。
- 所有图片和数据只在你的浏览器里，不上传任何服务器；清单存在 localStorage，清浏览器数据会丢失。
- 不自动登录、不抓取 Naver Map 页面，只生成官方搜索链接。
- 比对基于你手工带回来的文字资料；攻略只有模糊中文名时工具会诚实地说「证据不够」，不会假装确定。

## 后续可扩展

- OCR：从截图自动读出店名 / 地址 / 电话，减少手动输入。
- 接入 Naver / Kakao 官方地点搜索 API，自动列出候选地点（需申请密钥，可能有费用）。
- 行程分组：按日期 / 城市 / 类别整理清单。
- 部署成 PWA，可「添加到主屏幕」像 App 一样使用。
